# POV Overlay

本地 GPX 视频叠加层编辑器。前端采用 **Vue 3 + TypeScript + Hikari**，桌面端采用 **Tauri 2 + Rust**。

支持画布排布、实时预览和独立透明或绿幕叠加层视频导出。视频与图片素材用于预览。

## 启动

要求 Node.js 22.13+、pnpm 11.24.0（版本见 `package.json` 的 `packageManager`）、Rust stable，以及 [Tauri 系统开发依赖](https://v2.tauri.app/start/prerequisites/)。

```sh
pnpm install --frozen-lockfile
pnpm tauri dev
```

只启动浏览器开发预览：

```sh
pnpm dev
```

访问 `http://127.0.0.1:1420`，导入自己的 GPX。视频和图片均为可选背景；只有 GPX 也能播放预览。

## 当前功能

- 成功与错误提示使用右上角浮动通知，可关闭并自动消失，不挤占画布。
- 左侧为素材、同步与元素库，中间为预览画布，右侧为所选元素设置与数据采样/海拔；移除重复标签与常驻操作说明，必要帮助通过控件悬停提示提供。
- 多段 GPX 导入、启停、移除和时间拼合；支持任意素材导入顺序和文件拖放。
- 图片或视频背景；无背景时显示透明棋盘，纯 GPX 使用独立播放时钟。
- 可配置的速度平滑、刷新间隔、GPS 航向和累计距离。
- 右侧播放器底部叠加速度/海拔曲线，共用时间轴与播放指针；曲线默认收起，导入新的 GPX、视频或图片后也会收起；播放器右上角的「曲线」按钮可收起/展开，收起后保留播放与时间轴，并释放画布空间。悬停显示对应时刻的采样详情，点击曲线定位播放；聚焦后可用左右键移动 1 秒、Shift 移动 10 秒，Home/End 跳到首尾。速度复用当前平滑与归零设置，双纵轴分别使用 km/h 和米；缺失值与断档不连线，视频对齐后只绘制当前预览时段。
- 自定义 SVG 字段绑定，以及可手动添加的透明数据条。
- 可编辑的多行文本，点击插入省市区、道路、速度、里程等参数；地址通过高德逆地理编码获取。
- 左上角「文件」提供预设载入、命名保存与打开预设文件夹；工程保存/加载入口已移除。预设保存布局与采样配置。
- 新建画布为空，速度、经纬度等元素从左侧元素库手动添加，可自由拖动、缩放、显示/隐藏、锁定。
- 元素大小支持从 0% 调整到画布允许的最大尺寸，可拖动滑块或直接输入百分比；0% 不渲染，仍可从图层列表选中并恢复。
- 可调整位置百分比、大小、背景透明度、强调色；拖动时支持画布边缘、中心、安全边距，以及其他可见元素的边缘、中心和 8px 间距吸附，触发距离为 7px。锁定元素仍可作参照，隐藏元素不参与；显示实时参考线，按 Alt 临时关闭吸附。
- 画布元素右键可删除，聚焦画布元素后按 Delete/Backspace 也可删除，均可撤销；编辑输入框时不会误删元素。
- 编辑区域支持 25%–800% 视图缩放；Ctrl/⌘ + 滚轮以指针为中心缩放，滚轮、中键或手形工具平移，选择「适应」恢复。放大只影响编辑视图，不影响导出；拖动、吸附和键盘微调使用实际屏幕尺寸，可精确对齐。
- 支持撤销/重做、方向键逐像素微调，Shift + 方向键移动 10 像素。
- 播放/暂停、拖动时间轴、静音、回到视频起点；Space 切换播放。
- 按视频时间采样 GPX，速度显示为 km/h；经纬度保留 WGS84，不自动转换为 GCJ-02。

## 自动时间对齐

计算方式：

```text
偏移秒数 = (视频起始时间 − GPX 起始时间) / 1000
当前 GPX 时间 = GPX 起始时间 + 偏移秒数 × 1000 + 视频播放时间 × 1000
```

正偏移表示视频开始于 GPX 记录之后；负偏移表示视频先于 GPX 开始。偏移可为小数。

桌面端优先通过可选的 `ffprobe` 读取 QuickTime 拍摄时间、容器/视频流 `creation_time`，保留时区与毫秒。没有 `ffprobe` 时仍可直接读取 MP4/MOV 的 `mvhd` 时间，并通过系统 WebView 播放视频。浏览器开发模式读取 MP4/MOV 的 `mvhd` 时间。读取大型文件时只读取元数据块，不把整段视频载入内存。

- 时间戳统一换算为 UTC；界面中的日期与手动输入使用当前系统时区。
- 每段 GPX 支持「UTC 标注校正」，默认不校正。若设备把本地时间误写成 `Z`（UTC），选择实际记录时区。例如 `2026-10-22T18:39:45.000Z` 实际表示东八区 18:39:45 时，选择 `UTC+08:00（东八区）`，校正后的绝对时间为 `2026-10-22T10:39:45.000Z`，东八区界面显示 18:39:45。正确带时区的文件保持「不校正（按文件）」。
- 校正应用于该来源的全部轨迹点，再进行拼合、采样和视频对齐；不修改原始导入数据，切换时区不会累计偏移。校正作用于当前素材。当前支持固定 UTC 偏移，不自动处理夏令时。
- 缺少有效拍摄时间时明确提示，并允许手动填写视频起始时间或设置偏移；不使用文件修改时间猜测。
- 元数据可能是剪辑、转码或设备时钟设置产生的时间，用户可手动校准。
- 超出 GPX 覆盖范围、跨轨迹段、孤立定位点或相邻点相隔超过 30 秒时显示 `—`，实时速度、坐标不保持旧读数或跨断档插值；行程累计值独立处理。每段获得第二个定位点前，速度显示 `—`，不借用未来速度；有定位坐标但无法估算速度时保留坐标。刷新快照也必须服从当前实际时间的覆盖范围。
- GPX 支持多个 `trk/trkseg`，要求至少两个有效的带时间戳轨迹点；排序并忽略重复时间和缺少时间的点。
- 视频播放能力取决于系统 WebView 与解码器，建议使用 H.264 MP4。这个版本不自动转码。

macOS 可选安装元数据增强工具：

```sh
brew install ffmpeg
```

## 平滑、刷新与航向

默认 **7 个定位点**的居中窗口（当前点与前后各 3 点），可选择 3–61 的奇数点数或关闭平滑。参考 [gpx.studio 的双向窗口速度统计](https://github.com/gpxstudio/gpx.studio/blob/main/gpx/src/gpx.ts#L906-L922)，用窗口累计路程除以实际经过时间，而不是平均各点瞬时速度；时间分母至少 1 秒。上游按时间选择窗口，本项目按点数选择，采样不规则时不会把 7 点误当成 7 秒。窗口在连续段首尾截短，不跨分段、断档或异常末点。居中平滑会使用窗口内后续定位点，起停变化可能提前反映在平滑速度中；但每段首点与首个观测区间仍不显示速度。随后用单调三次 Hermite 曲线补足采样间隔，避免速度过冲或负值。

额外识别孤立的往返 GPS 跳点：只有两侧速度都显著高于相邻运动速度、且绕行距离明显大于直接连接时，才在速度与航向估计中用相邻可信点的插值替代。正常持续高速和转弯不设置固定限速。该保护不能识别所有持续定位偏差；原始坐标、原始点速度、工程素材和累计距离均不改写。末点没有后续定位来验证：若最后一段的速度突增超过此前若干有效区间的中位水平，会标记为速度无效并显示 `—`，不强行填 0 或维持旧读数。关闭平滑时使用原始点速度并关闭内部往返跳点修正，首点和异常末点的有效性检查仍生效。被标记为无效的末点不参与前面各点的窗口累计，避免异常距离向前扩散。断档和显式分段之间不计算窗口。

速度归零阈值默认 **0.5 km/h**，可在数据采样中调整，0 表示关闭。平滑插值后的速度低于阈值时显示 0；同一连续段中沿用最后有效航向，不受低速漂移影响，也不跨断档继承方向。首次有效运动前没有可靠航向时显示 `—`。阈值随预设保存，旧文件默认 0.5 km/h。此设置不改写原始坐标或累计距离。

窗口点数随预设保存为 `smoothingPoints`。旧文件的 `smoothingSeconds` 仅用于兼容读取：原为 0 时保持关闭，正值迁移到默认 7 点，不把秒数直接当点数。

默认每 0.2 秒更新一次数据快照。刷新间隔与播放器帧率分开控制，SVG、速度和航向共享同一份采样快照。

航向使用球面初始方位角，正北 0°、正东 90°，顺时针增加；跨 359°/1° 按最短角度插值。小于 0.5 米的位移视为无法可靠定向，保留当前连续段内最后一个有效航向；新段没有有效方向时显示 `—`。航向和累计距离缓存在处理后的轨迹点及当前预览状态中。

## 多段 GPX 与轨迹预览

- 所有点按绝对时间排序，不把文件起始时间强制接到前一个文件末尾。
- 后导入的文件覆盖其连续记录区间中的旧点，避免两个重叠采样流交替产生速度尖峰。
- 可逐段启停或移除。默认允许连接不同文件的相邻点：间隔不超过 30 秒，且推算速度不超过 100 m/s；可取消连接。原文件的显式分段与较长断档始终保留。
- 时间轴分别显示每段有效覆盖范围，不把空档涂成有效数据。
- 轨迹缩略图使用含纬度修正的等距圆柱投影、日期变更线展开、统一缩放与 Ramer–Douglas–Peucker 简化；保持纵横比例和转弯，断档不连线，并标注当前位置。它是路线概览，不是在线地图底图。

## 叠加层视频导出

桌面版右上角「导出视频」可设置分辨率、0.1–120 fps 帧率和导出起止秒数。默认帧率推荐为数据刷新间隔的倒数（0.2 秒对应 5 fps），减少重复渲染与编码可加快导出；仍可手动提高帧率。若在剪辑软件中制作 N 倍速视频，导出帧率可设为「目标帧率 ÷ N」，数据刷新间隔相应设为「N ÷ 目标帧率」秒。例如 8 倍速、目标 30 fps，可用 3.75 fps（约 4 fps）导出，并将数据刷新间隔设为约 0.267 秒，再在剪辑软件中加速 8 倍；本应用的导出帧率设置不会改变时间轴速度。默认优先提供 WebM / VP9 透明导出，也支持 MOV / ProRes 4444 与 MOV / PNG 无损，均保留透明通道；选择「绿幕」后默认使用体积更小的 MP4 / H.264，也可选 MOV。绿幕为纯绿色（#00FF00），不含 Alpha，需在剪辑软件中抠像，半透明边缘可能损失。ProRes 4444 便于后期编辑但文件较大，PNG 是另一种无损编码选择。透明 VP9 使用软件编码与有损压缩（CRF 30），通常比 MOV 更小；剪辑软件需支持 WebM Alpha，使用 FFmpeg 解码透明 WebM 时应指定 `-c:v libvpx-vp9` 作为输入解码器。需安装本地 FFmpeg（macOS：`brew install ffmpeg`），浏览器开发预览不编码视频。

输出包含当前可见元素及其位置、尺寸、配色和背景不透明度；背景视频、图片、棋盘格、编辑选框及播放器曲线均不导出。输出比例与画布不同时等比居中，空白区域随所选模式保持透明或纯绿。导出复用预览的速度平滑、归零阈值、航向、刷新间隔及视频时间偏移；断档时实时数据显示缺失值；当前/剩余里程保持最近的已知距离；剩余记录时间、UTC 时钟与行程时间进度按当前时间继续变化，轨迹前为 0/全程，轨迹结束后为全程/0。拖动到任意时间也能得到相同结果。帧数为 `ceil(导出时长 × fps)`，最后一帧在选定结束时间之前，输出时长向上取整到一帧。

前端以同一套 SVG 渲染内置和自定义元素，直接传输元素占用区域的 RGBA 像素；Rust 补齐完整背景后编码，避免逐帧 PNG 压缩与解压。同一画面可批量复用，输出仍保持设定帧率。只保留当前帧与元素缓存，不将整个视频载入内存。默认「优先硬件编码」跨平台检查 FFmpeg 已安装的编码器，按当前分辨率与帧率实际探测：H.264 尝试 VideoToolbox、NVENC、Quick Sync、AMF、VAAPI 与 V4L2；绿幕 VP9 尝试 Quick Sync/VAAPI；ProRes 尝试 VideoToolbox 且须通过 Alpha 解码检查。Linux VAAPI 会尝试可用渲染设备；每次硬件探测有超时保护。透明 VP9 与 PNG 没有支持当前 Alpha 管线的硬件路径，保留软件编码；不可用时自动使用软件编码，也可手动关闭。进度栏显示实际编码方式。导出有进度和取消按钮；失败或取消会清理临时输出，成功后才替换目标文件，并禁止覆盖当前预览视频。关闭窗口会取消其导出任务。素材与视频均在本地处理。

## SVG 元素

在「画布元素」中按运动、行程、时间、导航、地点分类，通过缩略图选择添加元素，或导入 SVG，或选择「添加数据条」一次添加航向、经纬度、时间、距离、海拔和速度六个独立元素。行程分类还可添加当前里程、剩余里程、剩余时间、总里程、总时长与进度。每项可单独拖动、缩放、隐藏、锁定，图层行右侧可直接删除，也能通过「添加数据项」单独添加。已有工程中的旧版内置数据条可选中后点击「拆分数据条」，保留位置、比例及外层样式；拆分和整组添加均支持一次撤销。自定义 SVG 保持原样。元素默认无背景；背景不透明度可设为 0–100%。桌面端从操作系统读取所有可用字体（含用户安装字体），字体下拉支持搜索、键盘选择与刷新；中文字体名随预设保存。浏览器开发模式在支持时使用 Local Font Access，需要浏览器授权，否则提供常见字体。每个元素可单独设置字体、主字号、粗体和斜体；单位与辅助文字保持相对字号，设置同步用于预览、导出和预设。SVG 中已转换为路径的字形不能改字体。SVG 自带的背景矩形和布局由作者决定，外层背景设置不会改写 SVG 内部设计。

```xml
<svg xmlns="http://www.w3.org/2000/svg" viewBox="0 0 500 120">
  <text x="20" y="70" font-size="48" fill="{$Color}">{$Speed} km/h</text>
  <g opacity="{$HasHeading}" transform="rotate({$Heading} 430 60)">
    <path d="M430 30 L415 80 L430 70 L445 80Z" fill="white"/>
  </g>
</svg>
```

| 字段                           | 含义                               |
| ------------------------------ | ---------------------------------- |
| `{$Speed}`                     | km/h，一位小数                     |
| `{$Latitude}` / `{$Longitude}` | WGS84 十进制度，六位小数           |
| `{$LatitudeDirection}` / `{$LongitudeDirection}` | 绝对值坐标、度号及 N/S、E/W 后缀；缺失时显示 `—` |
| `{$CompassOffset}` | Minecraft 指南针贴图的水平帧偏移（32 帧，每帧 16px）；无航向时配合 `{$HasHeading}` 隐藏 |
| `{$Elevation}`                 | 海拔米，一位小数                   |
| `{$Heading}`                   | 正北为 0° 的航向，一位小数         |
| `{$Distance}`                  | 累计公里，两位小数，不计跨断档距离 |
| `{$RemainingDistance}` / `{$TotalDistance}` | 剩余/总里程（km） |
| `{$RemainingTime}` / `{$TotalTime}` | 剩余/总 GPX 记录时间（不是预测到达时间） |
| `{$Progress}` | 已完成记录时间百分比（0–100），断档继续变化 |
| `{$ProgressRatio}` / `{$ProgressPercent}` | 时间进度 0–1 / 0–100 的高精度图形数值 |
| `{$DistanceProgress}` | 已知里程百分比，缺少 GPS 时保持最近距离 |
| `{$Elapsed}`                   | 当前播放时间                       |
| `{$Timestamp}`                 | 当前快照的 UTC ISO 时间            |
| `{$Color}`                     | 元素强调色                         |
| `{$HasData}` / `{$HasHeading}` | 1 或 0，可用于透明度               |
| `{$Province}` / `{$City}` / `{$District}` | 当前省、市、区名称 |
| `{$Street}` / `{$Road}` | 行政街道 / 当前道路名称，两个独立字段 |
| `{$HasAddress}` | 有地址结果时为 1，否则为 0 |
| `{$HasSpeed}` | 速度有效时为 1；未获得足够定位或速度无效时为 0 |

SVG 保留 viewBox、局部渐变和样式；脚本、HTML、外部资源与事件处理器会被清理。模板以独立 SVG 图片渲染，样式不影响编辑器。上限 2 MB。图片背景支持 PNG/JPEG/WebP/GIF/AVIF，上限 20 MB。

字体选择展开后直接搜索并选取，使用 Hikari 原生选择面板、搜索框与菜单。字体、粗体和斜体覆盖直接写到文字节点，避免模板内联样式使选择不生效；未设置的字重、颜色与相对字号仍保留。字体需安装在当前电脑，已转为路径的文字仍保持原字形。

数据条参考了用户提供的 [gpxutil](https://github.com/DingJunyao/gpxutil) 画面布局方向，自行实现了方向、经纬度、时间、距离、海拔、速度字段，不包含道路名称或逆地理编码。

## 预设

左上角「文件」提供载入预设、保存预设和打开预设文件夹。保存时可输入独立名称，同名保存更新原预设。预设采用 `.preset.json`，包含元素、SVG、样式、画布比例及采样设置；素材单独导入，视图缩放和平移不写入预设。

桌面端直接保存到 Tauri 配置目录的 `presets/`，载入时优先展示本地列表，按最近修改排序，也可从文件导入。使用临时文件加原子替换；浏览器模式下载/上传 JSON。高德 Key 独立保存在本机，预设只记录地图来源。

界面组件只负责展示和事件绑定；composables 按素材、对齐、播放、画布尺寸、组件布局、时间轴、快捷键与文件拖放分别管理状态。`editor/createEditor.ts` 只组合这些控制器，`editor/context.ts` 向组件提供类型化上下文。

Rust 依赖方向为 `commands → application → domain / infrastructure`，基础设施实现依赖领域类型，领域层不依赖 Tauri、文件系统或命令层。所有 Rust 源码已统一迁入 `src-tauri`，根 `src/` 与独立的 `pov-core` 工程已合并。

原有 SRT 功能位于 `application/subtitle_export.rs`，以显式输出路径调用；地图实验位于 `infrastructure/map_renderer.rs`，通过可选的 `map-rendering` feature 启用，地图 I/O 不再放在轨迹点模型里。这些库功能不作为编辑器的合成导出入口。

桌面导入使用 Rust 解析 GPX。浏览器开发模式保留 TypeScript 解析适配；两者均有覆盖重复点、断档、时区与跨日期变更线的测试。播放逐帧更新在前端完成，不进行逐帧 IPC。

界面控件统一直接使用 Hikari 官方 Vue 组件：按钮、图标按钮、输入框、数字输入、选择器、复选框、开关、滑块、标签、颜色选择、菜单、弹窗、进度和通知；悬停帮助使用 Hikari 官方 tooltip bridge。字体筛选与字段插入只组织业务数据，不自制对应的输入、列表弹层或控件外观；应用样式仅负责业务布局和画布交互，主题通过 Hikari 颜色通道配置。文件选择保留隐藏的原生 file input 作为浏览器适配。

Hikari 采用官方 Vue 源码包，并使用 Vue JSX 插件编译 TSX。开发依赖预构建排除 Hikari 源码，嵌套的 CommonJS 依赖单独预构建，避免 TSX 被当作 React 编译；组件内置文案使用简体中文。版本由 `pnpm-lock.yaml` 锁定。

导航分类可添加路线 SVG：支持全程或按前后时长截取局部路线，保留断档，标示当前位置及方向，可选择航向朝上；局部路线以当前位置为中心，轨迹起止处保留空白；轮廓与采样缓存复用，随布局导出。

当前不提供背景视频合成或 HEVC 预览代理。预设需手动保存。

## 应用设置

顶栏齿轮打开独立设置页；返回编辑器保留素材、布局和播放位置，打开设置会暂停播放和地图预览请求；设置更改后自动保存，数字输入短暂合并写入，失焦或返回编辑器时立即保存，不提供额外保存按钮。默认地图来源只影响新添加的小地图，已有元素在右侧单独切换。

- 高德 Web 服务 API Key 在此配置、替换或删除，只保存于 Tauri 配置目录，界面只读取是否已配置，预设不包含 Key；兼容已有的 `amap.key`。
- 可配置地图加载延迟（默认 180ms）、瓦片并发（默认 2）、高德请求最小间隔（默认 500ms），避免拖动产生过量请求；新的位置未加载完成时保留上一幅地图。
- 可查看缓存大小和位置、打开缓存文件夹、清空地图/地址/海拔缓存；静态图缓存天数与磁盘容量上限可调整，API Key 和素材不会被清除。
- 浏览器开发模式只保存非敏感偏好与使用 OSM HTTP 缓存；API Key、第三方底图代理与磁盘缓存管理在桌面应用使用。地图数据来源链接可直接打开服务官网。

### SVG 动态图形范例

指针时速表与速度进度条位于「运动」，进度环位于「行程」；每个范例卡片可打开源文件位置，已导入 SVG 也可在右侧属性标题处打开源文件位置。原文件失效或发行版没有源码目录时，在配置目录生成可查看的 SVG 副本；浏览器模式下载源码。范例源文件位于 `ui/examples/`，可自行修改后导入。

另提供数字时速、胶囊时速、山形海拔和方括号经纬度样式。导航分类中的经纬度默认为纬度在上、经度在下，并按坐标显示 N/S、E/W；原始十进制度字段保持兼容。Minecraft 指南针使用内嵌的 Java Edition 1.21.5 原版像素贴图，32 帧按当前航向选择（正北 0°、正东 90°），缺少可靠航向时隐藏，不虚构方向；预览和视频导出均不下载贴图。素材来源见 [ASSETS.md](ui/examples/ASSETS.md)。

SVG 通过数值字段控制几何图形，不执行 JavaScript 或任意表达式：

- `{$SpeedRatio}`：当前速度 / 元素「速度满刻度」，限制在 0–1，适合 `scale({$SpeedRatio} 1)`。
- `{$SpeedPercent}`：0–100，适合路径 `pathLength="100" stroke-dasharray="{$SpeedPercent} 100"`。
- `{$SpeedAngle}`：−90° 到 +90°，适合以中心点旋转半圆时速表指针。
- `{$SpeedColor}`：满刻度 50% 以下绿色、50–80% 黄色、80% 以上红色。
- `{$HasSpeed}`：速度缺失时为 0；图形用它控制透明度，文字速度仍显示 `—`。
- `{$ProgressPercent}`：行程时间百分比，用于圆环 `stroke-dasharray`；GPX 断档时继续前进。数字标签可用 `{$Progress}`，按已知距离统计时用 `{$DistanceProgress}`。

满刻度默认 60 km/h，每个元素可独立调整。速度超过满刻度时图形停在最大值，数字继续显示真实速度。静态打开范例不会自动采样，动态字段由本应用在预览和导出时替换。


### 小地图

导航分类中「路线」「小地图」使用当前 GPX 生成缩略图；添加小地图后可在右侧选择 OpenStreetMap 或高德地图。高德使用官方静态地图 API，需先在独立设置页配置自己的 Web 服务 Key（只保存在本机配置目录，不进入预设）；采用本地 WGS84→GCJ-02 近似转换，不修改原始轨迹。高德最大缩放 17 级，使用静态图对应的 512 像素投影尺度绘制轨迹，API 按 64 像素区域复用图像；底图平移与轨迹、当前位置使用同一投影。

拖动进度条时按最新位置合并预览，未开始的过期请求会被丢弃；同一地图资源共享请求，完成缓存与请求队列分别管理。新位置加载期间保留上一帧并显示加载状态，导出仍逐帧等待正确资源。

小地图可在右侧设置 0–100% 的「地图不透明度」，对整个地图画面生效，预览、透明视频导出及预设保存保持一致；旧预设默认 100%。

OpenStreetMap 小地图支持圆形/方形、2–19 级缩放、路线叠加和航向朝上。仅在显式添加/载入小地图后按当前视图联网请求，不上传整条 GPX。桌面端由 Rust 获取并持久缓存瓦片 7 天，浏览器开发模式使用 HTTP 缓存；没有后台预取。透明视频导出包含地图、当前位置与设置的透明度，嵌入瓦片避免跨域污染画布，加载失败会提示并中止导出。地图需网络或本地已有缓存，离线纯路线元素不依赖网络。OSM 使用 WGS84/Web Mercator；高德显示时另做坐标转换。

应用不额外生成地图底部版权条。公开使用地图时仍需按服务要求安排可见署名；OSM 的要求见 [OSM 瓦片使用政策](https://operations.osmfoundation.org/policies/tiles/)。地图服务会收到所请求瓦片的位置与网络信息；较长导出会按需加载经过区域的瓦片。


### 海拔补全与替换

右侧海拔处显示数据来源 Mapterhorn，点击会在系统浏览器打开官网。右侧数据采样中的「海拔」提供「替换原始数据」按钮，一次获取已启用轨迹的地形海拔并替换显示值；完成后可用旁边的恢复按钮还原原始海拔。参考 [gpx.studio 的取样方法](https://github.com/gpxstudio/gpx.studio/blob/main/website/src/lib/utils.ts)，直接连接 [Mapterhorn 官方瓦片服务](https://mapterhorn.com/data-access/)：12 级、512×512 WebP Terrarium 瓦片，按 `R×256 + G + B/256 − 32768` 解码并双线性插值。桌面端由 Rust 下载、缓存、解码和采样；按瓦片合并请求，不逐个定位点重复下载。

原始 GPX 海拔保留；替换值独立保存，可「恢复原始」，替换值用于当前素材。无有效地形数据的点保留原值，不把失败填成 0；网络失败不应用本次更改。支持进度与取消，取消后不应用正在获取的结果（当前网络请求最多等到超时结束）。浏览器开发预览不提供地形获取，需在桌面版操作。地形海拔与设备测得的海拔可能存在差异；数据来源见 [Mapterhorn 署名](https://mapterhorn.com/attribution/)。

高德静态地图接口及 Key 说明见[官方文档](https://lbs.amap.com/api/webservice/guide/api/staticmaps)。应用不再额外拼接服务图像的底部署名条；API 配额取决于自己的账号。

桌面地图与地形缓存采用按资源合并下载，缓存读取不会等待其他位置的网络请求；连接/总请求分别有 4/10 秒超时。OpenStreetMap 瓦片缓存 7 天、海拔瓦片缓存 30 天，高德静态地图默认缓存 30 天（可设置）。过期资源刷新失败时保留已有图像；失败响应不写入缓存。缓存不包含 API Key，容量默认 512 MB，超过后按文件写入时间清理较旧资源。清空缓存不会移除素材、预设或 Key。

### 地点与路名

「地点」分类提供当前省、当前市、当前区、当前街道和当前路名五个独立 SVG 元素，字体、字号、位置与其他元素一样单独编辑，也能在自定义 SVG 中绑定地址字段。桌面应用使用设置页中的高德 Web 服务 Key，按 [高德逆地理编码 API](https://lbs.amap.com/api/webservice/guide/api/georegeo) 查询；街道对应行政乡镇/街道（`township`），与道路名称分开。

在顶栏齿轮「设置 → API Key」填写高德 Web 服务 Key，供小地图与逆地理编码共用。左侧元素库点击「添加文本」，选中后在右侧「文本内容」直接编辑文字，使用「插入参数」将字段插入光标处或替换选中文字，离开输入框时应用修改。例如：

```text
{$Province} {$City} {$District}
当前道路：{$Road} · {$Speed} km/h
```

可自由组合普通文字与上表 SVG 参数，单位文字自行填写，按 Enter 换行。文字按纯文本转义，不执行 HTML/SVG；缺失字段显示 `—`。每个文本最多 2000 个字符、20 行，过长的单行会压缩到文本框宽度，可手动换行。支持现有字体、颜色、布局、锁定和撤销/重做，预览与导出共用渲染。预设及兼容工程在 SVG 元素中增加可选 `textTemplate`，载入时从文本重新生成并校验 SVG，旧文件仍按原方式载入。API Key 独立保存于本机，不进入文本或预设；不含地址字段的文本无需联网。

地址查询由 Rust 执行：原始 WGS84 坐标转换为高德坐标，提取行政区、附近道路和路口。路口约 35 米内参考同一连续段中约 80 米前的轨迹位置（连续段不足时使用段内最早位置），优先选择来向道路，避免直行过路口时跳到相交道路；参考位置尽量落在整个路口范围之前，稀疏轨迹按累计里程插值得到来向位置。离开路口后按当前附近道路更新。选择基于 GPX 位置而非播放历史，拖动和导出使用相同规则。附近道路候选仍可能无法区分平行道路、辅路和高架，不构成完整路网匹配；服务没有名称时显示 `—`。

五个元素共享结果。设置 → 道路信息提供「逆地理编码间隔（秒）」，默认 5 秒，允许 1–300 秒（支持小数），独立于运动数据刷新间隔和高德网络请求间隔。1 秒为本应用防止过密采样的下限，并非高德官方配额要求。按每个连续轨迹段的起点划分固定时间桶，每桶使用起点位置，预览、拖动时间轴与导出共用；断档、新段重新采样，不沿用前段地址，也不从前段查询来向。间隔越大，转弯后的路名更新可能越晚。地址间隔仅保存在本机应用设置中，不写入预设。

取样位置仍按约 20 米网格合并查询，缓存命中不重复联网；短暂合并拖动请求。来向地址仅在当前附近有路口时额外查询，因此一次地址更新最多请求两个位置；实际网络请求仍受「高德网络请求间隔」限制，导出无需按现实时间等待每个采样桶过去。原始响应持久缓存 30 天，与底图、静态图和海拔共用磁盘容量上限与清理操作。导出等待对应位置的地址，复用缓存；查询失败会提示并停止导出。无 GPX 数据的区间不联网、不沿用旧地名。添加/载入可见地址元素才会请求服务，服务会收到当前与必要的来向坐标，不发送整条轨迹；Key 和查询结果不写入预设。

## 道路名称与编号

在「画布元素 → 地点」分别添加「道路名称」和「道路编号」，各自移动、缩放、锁定、显隐与保存预设。编号元素仅显示当前道路对应的 SVG 牌子，无可靠编号时完全透明。名称的中文与英文两行可分别设置字号。编号牌复用交通牌制作器的专用字体矢量路径，预览和导出使用同一版式。旧版组合元素仍兼容，右侧「拆分名称与编号」可将其变为两个独立元素，保留编号表与样式，支持一次撤销。

所有「添加文本」创建的多行文本都提供「第 N 行字号」（8–200），每行独立调整；「自动」恢复跟随元素的整体字号。逐行字号随元素和预设保存，支持撤销、重做和锁定，行距与长行适配按该行实际字号计算。编辑文本增减行时，按行号保留仍存在的设置，新行跟随整体字号。

右侧「道路编号表」按道路名称和省市逐条维护编号、类别；可自行添加、删除记录，点击「应用」保存，支持撤销和重做。省市留空时匹配该名称的所有地区，填写时使用高德返回的完整省市名称；更具体的地区记录优先。编号留空表示该记录不显示编号牌。道路表属于当前道路编号元素，随预设保存（最多 2000 条），不同元素可分别配置。旧版元素级统一编号与类别因缺少道路范围，在恢复时不再生效。

正常播放或拖动时，已查询到的道路会在本次轨迹会话中汇总；打开编号表可看到尚未填写的道路，不额外发起请求。「识别整条路线」由用户主动启动，按设置的逆地理编码间隔（默认 5 秒）扫描整个 GPX，并显示进度、支持取消；复用原有高德缓存、请求节流和路口来向处理，断档及新段独立采样。取消或失败保留已发现的记录；更换轨迹时停止扫描并清除未保存的发现列表。短于采样间隔的道路可能漏检，可手动添加。自动发现不会覆盖已有编号，包括已设置的全地区记录。

[高德逆地理编码](https://lbs.amap.com/api/webservice/guide/api/georegeo)的道路对象仅提供名称、内部 ID、距离、方位和位置，没有单独的公路编号或英文名称字段。应用不再内置按路名套用的编号表；仅从道路名称中的明确 G/S/X/Y 编号或三位数字加“国道/省道/县道/乡道”提取编号，其他情况由用户填写。国高、省高与普通国省县乡道分别生成对应编号牌，保留 G0421 等前导零；三位 S 编号根据名称中的“高速”区分省高速与普通省道，表内也可手动指定。无匹配记录且无明确编号时，只显示道路名称，不保留上一条路的编号。省高速简称来自当前位置的省份。

开启「显示可用英文」时，目前仅为沈海高速、宁信高速显示内置英文，其余名称仍显示中文，不调用翻译服务。需要桌面端配置高德 Key 并加载 GPX；浏览器开发模式仍不执行实际地址查询。预设中保存用户应用的道路表，不保存 API Key 或轨迹坐标。

## 道路交通牌制作

顶栏「道路交通牌」进入独立页面，无需导入 GPX。分为道路名称标识、交叉路口、地点距离标识三类。初始提供可编辑的默认标牌，也可从「添加标牌」选择空白模板；支持切换、上移/下移和删除，返回编辑器后保留本次列表，重启后恢复默认列表。界面直接使用 Hikari 官方组件，不提供「加入画布」。

预览默认开启「编辑文字」：点击文字后可拖动位置，拖右下角手柄等比缩放；选中后方向键移动 1 个输出像素，Shift 加方向键移动 10 像素。右侧「文字排版」可选择文字、输入 X/Y 和字高（均为输出像素），并还原当前或全部文字。位置与大小约束在牌面内，调整会用于预览与 SVG 路径导出；选择框和手柄不会导出。文字排版按每张标牌分别保留，仍仅保留当前会话。

道路名称类包含国家/省级高速、国道/省道/县道/乡道编号、城市路名和无编号快速路名。编号只填写数字，前缀自动生成；省级高速另填省份简称，高速简称可选。交叉路口包含竖/横式丁字路口、十字、分隔式、环岛、堆叠式和车道式；地点距离最多三行。各模板支持手动英文/拼音、方向、距离以及 128–7680 px 输出宽度，文字超宽时等比缩小。

「导出 SVG」在桌面端选择保存位置，使用临时文件加原子替换；浏览器下载 SVG。文字统一导出为矢量路径，无需在目标电脑安装字体。生成结果仍遵循 SVG 2 MB 限制。预览与矢量导出共用字形与排版，放大预览不改变导出尺寸。所有数据在本地处理。

字体使用用户提供的 A/B/C 型 `jtbz_*.ttf`，连同原始使用说明保存在 `src-tauri/resources/fonts/` 并通过 Tauri resources 打包。桌面端按 A/B/C 白名单读取，浏览器由 Vite 提供同一份资源；按附录 B 自动选型：一般文字（含英文、距离）使用 A 型，道路/出口编号使用 B 型；C 型仅适用于箭杆内道路编号。不再提供整牌统一 B/C 字体切换。字形由 OpenType.js 读取，以实际轮廓包围盒计算字高和排布，转换为路径，不依赖系统安装字体，也不在每张 SVG 中重复嵌入整套字体。遇到缺字会提示。字体保留原始使用说明，不声明为本项目原创或额外开源授权资产。

版式依据用户提供的 GB 5768.2—2022：图 210–213、256–257，交叉路口图形式/堆叠式图示，以及附录 C 的高速牌字高与面板比例。普通国家/省级高速主编号采用等高字符，四位编号的后两位按主编号字高的 2/3 绘制；带名称与不带名称采用不同的面板高度。SVG 的 RGB 颜色用于屏幕表现，圆角与部分留白根据图示确定。

功能参考 [SignGenerator](https://github.com/fredqin2006-X/SignGenerator)、[gpxutil](https://github.com/DingJunyao/gpxutil#生成道路编号标志) 与文章[用代码绘制道路编号标志](https://4ading.com/posts/draw_road_number_sign_by_code/)。未引入上游应用源码、React、上游 SVG 资产或生成模块；领域模型、SVG 几何、字体排版和界面均在本项目独立实现。当前覆盖常用素材版式，复杂多出口枢纽、京津冀高速专门样式、多语种、实物安装与反光材料不在本次范围；当前支持文字移动与等比缩放，尚不提供箭头和牌面形状的任意对象编辑。用于视频和图片素材，不宣称覆盖整套国标或替代工程设计审查。

道路交通牌左侧使用 Hikari 彩色类别标签（高速深绿色、国道红色、省道黄色、普通道路蓝色），并提供 GB 5768.2—2022 图 C.3、205–208、213、259–261、B.1 的默认标牌。示例直接作为左侧默认标牌，可编辑、排序或删除；不同标牌之间互不影响。带名称高速牌的一、两位编号采用 125∶120 比例，四位采用 170∶120；长名称自动缩小字高，短名称保持居中间距。交叉路口提供竖/横式丁字路口、十字、分隔式、环岛、堆叠与车道式布局；方位、端点地点与道路编号可分别设置。箭杆上的编号用 C 型，其他编号用 B 型，普通文字和地点距离用 A 型。地点距离支持普通地点、道路编号牌和蓝底路名牌，按距离由近到远排版，距离数字按内置字体的字形宽度预留空间，保持完整字高与数字字距，并与较小的 km 单位共用底边；编号牌与该行中心对齐。堆叠式指路每行的箭头与文字共用中心线，环岛端点名称放大并采用统一字高，支路与圆环以相切曲线连接，入口旁的开口沿圆的半径方向直切，与圆周局部切线垂直。示例是版式参考，不能代替交通工程设计审核。
