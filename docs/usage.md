# 使用指南

[返回 README](../README.md)

## 画布与播放

- 成功与错误提示使用右上角浮动通知，可关闭并自动消失，不挤占画布。
- 左侧为素材、同步与元素库，中间为预览画布，右侧为所选元素设置与数据采样/海拔；移除重复标签与常驻操作说明，必要帮助通过控件悬停提示提供。
- 多段 GPX 导入、启停、移除和时间拼合；支持任意素材导入顺序和文件拖放。
- 图片或视频背景；无背景时显示透明棋盘，纯 GPX 使用独立播放时钟。
- 可配置的速度平滑、刷新间隔、GPS 航向和累计距离。
- 右侧播放器底部叠加速度/海拔曲线，共用时间轴与播放指针；曲线默认收起，导入新的 GPX、视频或图片后也会收起；播放器右上角的「曲线」按钮可收起/展开，收起后保留播放与时间轴，并释放画布空间。悬停显示对应时刻的采样详情，点击曲线定位播放；聚焦后可用左右键移动 1 秒、Shift 移动 10 秒，Home/End 跳到首尾。速度复用当前平滑与归零设置，双纵轴分别使用 km/h 和米；缺失值与断档不连线，视频对齐后只绘制当前预览时段。
- 自定义 SVG 字段绑定，以及可手动添加的透明数据条。
- 可编辑的多行文本，点击插入省市区、道路、速度、里程等参数；地址通过高德逆地理编码获取。
- 左上角「文件」提供预设载入、命名保存与打开预设文件夹；工程保存/加载入口已移除。预设保存布局与采样配置。
- 新建画布为空，速度、经纬度等元素从左侧元素库手动添加，可自由拖动、缩放、显示/隐藏、锁定。
- 元素大小支持从 0% 调整到画布允许的最大尺寸，可拖动滑块或直接输入百分比；0% 不渲染，仍可从图层列表选中并恢复。
- 可调整位置百分比、大小、背景透明度、强调色；拖动时支持画布边缘、中心、安全边距，以及其他可见元素的边缘、中心和 8px 间距吸附，触发距离为 7px。锁定元素仍可作参照，隐藏元素不参与；显示实时参考线，按 Alt 临时关闭吸附。
- 画布元素右键可删除，聚焦画布元素后按 Delete/Backspace 也可删除，均可撤销；编辑输入框时不会误删元素。
- 编辑区域支持 25%–800% 视图缩放；Ctrl/⌘ + 滚轮以指针为中心缩放，滚轮、中键或手形工具平移，选择「适应」恢复。放大只影响编辑视图，不影响导出；拖动、吸附和键盘微调使用实际屏幕尺寸，可精确对齐。
- 支持撤销/重做、方向键逐像素微调，Shift + 方向键移动 10 像素。
- 播放/暂停、拖动时间轴、静音、回到视频起点；Space 切换播放。
- 按视频时间采样 GPX，速度显示为 km/h；经纬度保留 WGS84，不自动转换为 GCJ-02。

## 添加元素与字体

在「画布元素」中按运动、行程、时间、导航、地点分类，通过缩略图选择添加元素，或导入 SVG，或选择「添加数据条」一次添加航向、经纬度、时间、距离、海拔和速度六个独立元素。行程分类还可添加当前里程、剩余里程、剩余时间、总里程、总时长与进度。每项可单独拖动、缩放、隐藏、锁定，图层行右侧可直接删除，也能通过「添加数据项」单独添加。已有工程中的旧版内置数据条可选中后点击「拆分数据条」，保留位置、比例及外层样式；拆分和整组添加均支持一次撤销。自定义 SVG 保持原样。元素默认无背景；背景不透明度可设为 0–100%。桌面端从操作系统读取所有可用字体（含用户安装字体），字体下拉支持搜索、键盘选择与刷新；中文字体名随预设保存。浏览器开发模式在支持时使用 Local Font Access，需要浏览器授权，否则提供常见字体。每个元素可单独设置字体、主字号、粗体和斜体；单位与辅助文字保持相对字号，设置同步用于预览、导出和预设。SVG 中已转换为路径的字形不能改字体。SVG 自带的背景矩形和布局由作者决定，外层背景设置不会改写 SVG 内部设计。

图片背景支持 PNG/JPEG/WebP/GIF/AVIF，上限 20 MB。

## 预设

左上角「文件」提供载入预设、保存预设和打开预设文件夹。保存时可输入独立名称，同名保存更新原预设。预设采用 `.preset.json`，包含元素、SVG、样式、画布比例及采样设置；素材单独导入，视图缩放和平移不写入预设。

桌面端直接保存到 Tauri 配置目录的 `presets/`，载入时优先展示本地列表，按最近修改排序，也可从文件导入。使用临时文件加原子替换；浏览器模式下载/上传 JSON。高德 Key 独立保存在本机，预设只记录地图来源。

## 应用设置

「设置 → FFmpeg」可填写或选择 FFmpeg 可执行文件，并显示检测到的路径。留空自动查找系统 PATH，macOS 同时查找 `/opt/homebrew/bin/ffmpeg` 与 `/usr/local/bin/ffmpeg`；Windows 可选择 `ffmpeg.exe`。路径自动保存到本机 `app-settings.json`，重启后继续使用，不写入预设。手动路径优先，失效时明确报错；清空路径恢复自动检测。FFmpeg 所在文件夹内的 `ffprobe` / `ffprobe.exe` 会优先用于视频拍摄时间读取。此项需在桌面应用使用。

顶栏齿轮打开独立设置页；返回编辑器保留素材、布局和播放位置，打开设置会暂停播放和地图预览请求；设置更改后自动保存，数字输入短暂合并写入，失焦或返回编辑器时立即保存，不提供额外保存按钮。默认地图来源只影响新添加的小地图，已有元素在右侧单独切换。

- 高德 Web 服务 API Key 在此配置、替换或删除，只保存于 Tauri 配置目录，界面只读取是否已配置，预设不包含 Key；兼容已有的 `amap.key`。
- 可配置地图加载延迟（默认 180ms）、瓦片并发（默认 2）、高德请求最小间隔（默认 500ms），避免拖动产生过量请求；新的位置未加载完成时保留上一幅地图。
- 可查看缓存大小和位置、打开缓存文件夹、清空地图/地址/海拔缓存；静态图缓存天数与磁盘容量上限可调整，API Key 和素材不会被清除。
- 浏览器开发模式只保存非敏感偏好与使用 OSM HTTP 缓存；API Key、第三方底图代理与磁盘缓存管理在桌面应用使用。地图数据来源链接可直接打开服务官网。

## 当前限制

当前不提供背景视频合成或 HEVC 预览代理。预设需手动保存。
