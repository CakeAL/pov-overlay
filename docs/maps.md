# 地图、海拔与地点

[返回 README](../README.md)

## 离线路线

导航分类可添加路线 SVG：支持全程或按前后时长截取局部路线，保留断档，标示当前位置及方向，可选择航向朝上；局部路线以当前位置为中心，轨迹起止处保留空白；轮廓与采样缓存复用，随布局导出。

## 小地图

导航分类中「路线」「小地图」使用当前 GPX 生成缩略图；添加小地图后可在右侧选择 OpenStreetMap 或高德地图。高德使用官方静态地图 API，需先在独立设置页配置自己的 Web 服务 Key（只保存在本机配置目录，不进入预设）；采用本地 WGS84→GCJ-02 近似转换，不修改原始轨迹。高德最大缩放 17 级，使用静态图对应的 512 像素投影尺度绘制轨迹，API 按 64 像素区域复用图像；底图平移与轨迹、当前位置使用同一投影。

拖动进度条时按最新位置合并预览，未开始的过期请求会被丢弃；同一地图资源共享请求，完成缓存与请求队列分别管理。新位置加载期间保留上一帧并显示加载状态，导出仍逐帧等待正确资源。

小地图可在右侧设置 0–100% 的「地图不透明度」，对整个地图画面生效，预览、透明视频导出及预设保存保持一致；旧预设默认 100%。

OpenStreetMap 小地图支持圆形/方形、2–19 级缩放、路线叠加和航向朝上。仅在显式添加/载入小地图后按当前视图联网请求，不上传整条 GPX。桌面端由 Rust 获取并持久缓存瓦片 7 天，浏览器开发模式使用 HTTP 缓存；没有后台预取。透明视频导出包含地图、当前位置与设置的透明度，嵌入瓦片避免跨域污染画布，加载失败会提示并中止导出。地图需网络或本地已有缓存，离线纯路线元素不依赖网络。OSM 使用 WGS84/Web Mercator；高德显示时另做坐标转换。

应用不额外生成地图底部版权条。公开使用地图时仍需按服务要求安排可见署名；OSM 的要求见 [OSM 瓦片使用政策](https://operations.osmfoundation.org/policies/tiles/)。地图服务会收到所请求瓦片的位置与网络信息；较长导出会按需加载经过区域的瓦片。

高德静态地图接口及 Key 说明见[官方文档](https://lbs.amap.com/api/webservice/guide/api/staticmaps)。应用不再额外拼接服务图像的底部署名条；API 配额取决于自己的账号。

## 海拔补全与替换

右侧海拔处显示数据来源 Mapterhorn，点击会在系统浏览器打开官网。右侧数据采样中的「海拔」提供「替换原始数据」按钮，一次获取已启用轨迹的地形海拔并替换显示值；完成后可用旁边的恢复按钮还原原始海拔。参考 [gpx.studio 的取样方法](https://github.com/gpxstudio/gpx.studio/blob/main/website/src/lib/utils.ts)，直接连接 [Mapterhorn 官方瓦片服务](https://mapterhorn.com/data-access/)：12 级、512×512 WebP Terrarium 瓦片，按 `R×256 + G + B/256 − 32768` 解码并双线性插值。桌面端由 Rust 下载、缓存、解码和采样；按瓦片合并请求，不逐个定位点重复下载。

原始 GPX 海拔保留；替换值独立保存，可「恢复原始」，替换值用于当前素材。无有效地形数据的点保留原值，不把失败填成 0；网络失败不应用本次更改。支持进度与取消，取消后不应用正在获取的结果（当前网络请求最多等到超时结束）。浏览器开发预览不提供地形获取，需在桌面版操作。地形海拔与设备测得的海拔可能存在差异；数据来源见 [Mapterhorn 署名](https://mapterhorn.com/attribution/)。

## 缓存

桌面地图与地形缓存采用按资源合并下载，缓存读取不会等待其他位置的网络请求；连接/总请求分别有 4/10 秒超时。OpenStreetMap 瓦片缓存 7 天、海拔瓦片缓存 30 天，高德静态地图默认缓存 30 天（可设置）。过期资源刷新失败时保留已有图像；失败响应不写入缓存。缓存不包含 API Key，容量默认 512 MB，超过后按文件写入时间清理较旧资源。清空缓存不会移除素材、预设或 Key。

## 地点与路名

「地点」分类提供当前省、当前市、当前区、当前街道和当前路名五个独立 SVG 元素，字体、字号、位置与其他元素一样单独编辑，也能在自定义 SVG 中绑定地址字段。桌面应用使用设置页中的高德 Web 服务 Key，按 [高德逆地理编码 API](https://lbs.amap.com/api/webservice/guide/api/georegeo) 查询；街道对应行政乡镇/街道（`township`），与道路名称分开。

在顶栏齿轮「设置 → API Key」填写高德 Web 服务 Key，供小地图与逆地理编码共用。左侧元素库点击「添加文本」，选中后在右侧「文本内容」直接编辑文字，使用「插入参数」将字段插入光标处或替换选中文字，离开输入框时应用修改。例如：

```text
{$Province} {$City} {$District}
当前道路：{$Road} · {$Speed} km/h
```

可自由组合普通文字与[SVG 字段](svg.md#示例与字段)，单位文字自行填写，按 Enter 换行。文字按纯文本转义，不执行 HTML/SVG；缺失字段显示 `—`。每个文本最多 2000 个字符、20 行，过长的单行会压缩到文本框宽度，可手动换行。支持现有字体、颜色、布局、锁定和撤销/重做，预览与导出共用渲染。预设及兼容工程在 SVG 元素中增加可选 `textTemplate`，载入时从文本重新生成并校验 SVG，旧文件仍按原方式载入。API Key 独立保存于本机，不进入文本或预设；不含地址字段的文本无需联网。

地址查询由 Rust 执行：原始 WGS84 坐标转换为高德坐标，提取行政区、附近道路和路口。路口约 35 米内参考同一连续段中约 80 米前的轨迹位置（连续段不足时使用段内最早位置），优先选择来向道路，避免直行过路口时跳到相交道路；参考位置尽量落在整个路口范围之前，稀疏轨迹按累计里程插值得到来向位置。离开路口后按当前附近道路更新。选择基于 GPX 位置而非播放历史，拖动和导出使用相同规则。附近道路候选仍可能无法区分平行道路、辅路和高架，不构成完整路网匹配；服务没有名称时显示 `—`。

五个元素共享结果。设置 → 道路信息提供「逆地理编码间隔（秒）」，默认 5 秒，允许 1–300 秒（支持小数），独立于运动数据刷新间隔和高德网络请求间隔。1 秒为本应用防止过密采样的下限，并非高德官方配额要求。按每个连续轨迹段的起点划分固定时间桶，每桶使用起点位置，预览、拖动时间轴与导出共用；断档、新段重新采样，不沿用前段地址，也不从前段查询来向。间隔越大，转弯后的路名更新可能越晚。地址间隔仅保存在本机应用设置中，不写入预设。

取样位置仍按约 20 米网格合并查询，缓存命中不重复联网；短暂合并拖动请求。来向地址仅在当前附近有路口时额外查询，因此一次地址更新最多请求两个位置；实际网络请求仍受「高德网络请求间隔」限制，导出无需按现实时间等待每个采样桶过去。原始响应持久缓存 30 天，与底图、静态图和海拔共用磁盘容量上限与清理操作。导出等待对应位置的地址，复用缓存；查询失败会提示并停止导出。无 GPX 数据的区间不联网、不沿用旧地名。添加/载入可见地址元素才会请求服务，服务会收到当前与必要的来向坐标，不发送整条轨迹；Key 和查询结果不写入预设。

所有「添加文本」创建的多行文本都提供「第 N 行字号」（8–200），每行独立调整；「自动」恢复跟随元素的整体字号。逐行字号随元素和预设保存，支持撤销、重做和锁定，行距与长行适配按该行实际字号计算。编辑文本增减行时，按行号保留仍存在的设置，新行跟随整体字号。

## 道路名称与编号

在「画布元素 → 地点」分别添加「道路名称」和「道路编号」，各自移动、缩放、锁定、显隐与保存预设。编号元素仅显示当前道路对应的 SVG 牌子，无可靠编号时完全透明。名称的中文与英文两行可分别设置字号。编号牌复用交通牌制作器的专用字体矢量路径，预览和导出使用同一版式。旧版组合元素仍兼容，右侧「拆分名称与编号」可将其变为两个独立元素，保留编号表与样式，支持一次撤销。

右侧「道路编号表」按道路名称和省市逐条维护编号、类别；可自行添加、删除记录，点击「应用」保存，支持撤销和重做。省市留空时匹配该名称的所有地区，填写时使用高德返回的完整省市名称；更具体的地区记录优先。编号留空表示该记录不显示编号牌。道路表属于当前道路编号元素，随预设保存（最多 2000 条），不同元素可分别配置。旧版元素级统一编号与类别因缺少道路范围，在恢复时不再生效。

正常播放或拖动时，已查询到的道路会在本次轨迹会话中汇总；打开编号表可看到尚未填写的道路，不额外发起请求。「识别整条路线」由用户主动启动，按设置的逆地理编码间隔（默认 5 秒）扫描整个 GPX，并显示进度、支持取消；复用原有高德缓存、请求节流和路口来向处理，断档及新段独立采样。取消或失败保留已发现的记录；更换轨迹时停止扫描并清除未保存的发现列表。短于采样间隔的道路可能漏检，可手动添加。自动发现不会覆盖已有编号，包括已设置的全地区记录。

[高德逆地理编码](https://lbs.amap.com/api/webservice/guide/api/georegeo)的道路对象仅提供名称、内部 ID、距离、方位和位置，没有单独的公路编号或英文名称字段。应用不再内置按路名套用的编号表；仅从道路名称中的明确 G/S/X/Y 编号或三位数字加“国道/省道/县道/乡道”提取编号，其他情况由用户填写。国高、省高与普通国省县乡道分别生成对应编号牌，保留 G0421 等前导零；三位 S 编号根据名称中的“高速”区分省高速与普通省道，表内也可手动指定。无匹配记录且无明确编号时，只显示道路名称，不保留上一条路的编号。省高速简称来自当前位置的省份。

开启「显示可用英文」时，目前仅为沈海高速、宁信高速显示内置英文，其余名称仍显示中文，不调用翻译服务。需要桌面端配置高德 Key 并加载 GPX；浏览器开发模式仍不执行实际地址查询。预设中保存用户应用的道路表，不保存 API Key 或轨迹坐标。
