# 道路交通牌制作

[返回 README](../README.md)

顶栏「道路交通牌」进入独立页面，无需导入 GPX。分为道路名称标识、交叉路口、地点距离标识三类。初始提供可编辑的默认标牌，也可从「添加标牌」选择空白模板；支持切换、上移/下移和删除，返回编辑器后保留本次列表，重启后恢复默认列表。界面直接使用 Hikari 官方组件，不提供「加入画布」。

预览默认开启「编辑文字」：点击文字后可拖动位置，拖右下角手柄等比缩放；选中后方向键移动 1 个输出像素，Shift 加方向键移动 10 像素。右侧「文字排版」可选择文字、输入 X/Y 和字高（均为输出像素），并还原当前或全部文字。位置与大小约束在牌面内，调整会用于预览与 SVG 路径导出；选择框和手柄不会导出。文字排版按每张标牌分别保留，仍仅保留当前会话。

道路名称类包含国家/省级高速、国道/省道/县道/乡道编号、城市路名和无编号快速路名。编号只填写数字，前缀自动生成；省级高速另填省份简称，高速简称可选。交叉路口包含竖/横式丁字路口、十字、分隔式、环岛、堆叠式和车道式；地点距离最多三行。各模板支持手动英文/拼音、方向、距离以及 128–7680 px 输出宽度，文字超宽时等比缩小。

「导出 SVG」在桌面端选择保存位置，使用临时文件加原子替换；浏览器下载 SVG。文字统一导出为矢量路径，无需在目标电脑安装字体。生成结果仍遵循 SVG 2 MB 限制。预览与矢量导出共用字形与排版，放大预览不改变导出尺寸。所有数据在本地处理。

字体使用用户提供的 A/B/C 型 `jtbz_*.ttf`，连同原始使用说明保存在 `src-tauri/resources/fonts/` 并通过 Tauri resources 打包。桌面端按 A/B/C 白名单读取，浏览器由 Vite 提供同一份资源；按附录 B 自动选型：一般文字（含英文、距离）使用 A 型，道路/出口编号使用 B 型；C 型仅适用于箭杆内道路编号。不再提供整牌统一 B/C 字体切换。字形由 OpenType.js 读取，以实际轮廓包围盒计算字高和排布，转换为路径，不依赖系统安装字体，也不在每张 SVG 中重复嵌入整套字体。遇到缺字会提示。字体保留原始使用说明，不声明为本项目原创或额外开源授权资产。

版式依据用户提供的 GB 5768.2—2022：图 210–213、256–257，交叉路口图形式/堆叠式图示，以及附录 C 的高速牌字高与面板比例。普通国家/省级高速主编号采用等高字符，四位编号的后两位按主编号字高的 2/3 绘制；带名称与不带名称采用不同的面板高度。SVG 的 RGB 颜色用于屏幕表现，圆角与部分留白根据图示确定。

功能参考 [SignGenerator](https://github.com/fredqin2006-X/SignGenerator)、[gpxutil](https://github.com/DingJunyao/gpxutil#生成道路编号标志) 与文章[用代码绘制道路编号标志](https://4ading.com/posts/draw_road_number_sign_by_code/)。未引入上游应用源码、React、上游 SVG 资产或生成模块；领域模型、SVG 几何、字体排版和界面均在本项目独立实现。当前覆盖常用素材版式，复杂多出口枢纽、京津冀高速专门样式、多语种、实物安装与反光材料不在本次范围；当前支持文字移动与等比缩放，尚不提供箭头和牌面形状的任意对象编辑。用于视频和图片素材，不宣称覆盖整套国标或替代工程设计审查。

道路交通牌左侧使用 Hikari 彩色类别标签（高速深绿色、国道红色、省道黄色、普通道路蓝色），并提供 GB 5768.2—2022 图 C.3、205–208、213、259–261、B.1 的默认标牌。示例直接作为左侧默认标牌，可编辑、排序或删除；不同标牌之间互不影响。带名称高速牌的一、两位编号采用 125∶120 比例，四位采用 170∶120；长名称自动缩小字高，短名称保持居中间距。交叉路口提供竖/横式丁字路口、十字、分隔式、环岛、堆叠与车道式布局；方位、端点地点与道路编号可分别设置。箭杆上的编号用 C 型，其他编号用 B 型，普通文字和地点距离用 A 型。地点距离支持普通地点、道路编号牌和蓝底路名牌，按距离由近到远排版，距离数字按内置字体的字形宽度预留空间，保持完整字高与数字字距，并与较小的 km 单位共用底边；编号牌与该行中心对齐。堆叠式指路每行的箭头与文字共用中心线，环岛端点名称放大并采用统一字高，支路与圆环以相切曲线连接，入口旁的开口沿圆的半径方向直切，与圆周局部切线垂直。示例是版式参考，不能代替交通工程设计审核。
